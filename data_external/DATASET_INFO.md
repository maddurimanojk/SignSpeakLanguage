# External Dataset Information — ISL Alphabet Image Dataset

- **Dataset Name**: Indian Sign Language (ISL) Alphabet Dataset
- **Repository**: `ayeshatasnim-h/Indian-Sign-Language-dataset`
- **URL**: [https://github.com/ayeshatasnim-h/Indian-Sign-Language-dataset](https://github.com/ayeshatasnim-h/Indian-Sign-Language-dataset)
- **Author/Owner**: Ayesha Tasnim (`ayeshatasnim-h`)
- **License**: Publicly available GitHub repository dataset (Unspecified / Open Access)
- **Download Date**: 2026-08-15
- **Class Count**: 26 alphabet gesture classes (`A` through `Z`)
- **Total Files**: 12,637 static image files (`.jpg`)
- **Format**: Static RGB hand gesture images
- **Note on INCLUDE Benchmark**: The INCLUDE dataset (Sridhar et al., ACM MM '20) is a separate video-based ISL word sign dataset. The current dataset evaluated here is the static ISL Alphabet Image Dataset from `ayeshatasnim-h/Indian-Sign-Language-dataset`.
